A faster drop-in for csv-reader 1.0.0 — identical answers on every case, about 2x faster on the practice set. `solve.js` re-implements csv-reader's exact broken-row policy from scratch (BOM, CRLF, lone CR, quoted fields, `quote_junk`, `unterminated_quote`, `short_row`/`long_row`) with a flat single-pass scanner instead of one character at a time.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```

`main.ts` reads every case from `$MAKEFUN_INPUT_DIR/cases.json`, answers each with `run` from `solve.js`, and writes `$MAKEFUN_OUTPUT_DIR/answers.json`.
